How to Host on GitHub Pages

You can have this live on the web for free in just 3 steps:

  1. Create a GitHub Repo: Go to github.com/new, name it (e.g. birthday-letter), and choose Public.
  2. Upload 2 Files:
    • Save this file as index.html.
    • Take your couple picture, name it photo.jpg, and upload it right beside index.html.
  3. Enable GitHub Pages: Go to your repo Settings → Pages (on the left menu). Under Branch, select main (root) and click Save.
✨ In about 60 seconds, your site will be live at:
https://<your-username>.github.io/birthday-letter/
